# 练习 15 - 获取书名！

你将获得一个对象数组，这些对象代表带有作者和书名的书籍，如下所示：

```javascript
const books = [
  {
    title: 'Book',
    author: 'Name'
  },
  {
    title: 'Book2',
    author: 'Name2'
  }
]
```

你的任务是编写一个函数，接收这个数组并返回一个书名数组：

```javascript
getTheTitles(books) // ['Book','Book2']
```

## 提示

- 你应该使用JavaScript内置方法来为你完成大部分工作！
